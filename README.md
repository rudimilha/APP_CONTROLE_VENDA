# Relatório de Desenvolvimento do Aplicativo

Desenvolvi o aplicativo Sistema de Clientes e Compras utilizando Flutter e Dart. Comecei criando a estrutura principal do projeto e organizando as informações nas classes Cliente, Produto e Compra. Depois, montei as quatro telas do aplicativo: Clientes, Produtos, Compras e Consulta, cada uma com sua função. Também criei a navegação na parte inferior da tela para facilitar a troca entre elas.

Em seguida, implementei os formulários para cadastrar clientes e produtos e registrar compras. Acrescentei algumas validações para evitar campos vazios, CPF duplicado e valores ou quantidades inválidos. Também configurei o cálculo do total das compras e a consulta dos registros. Durante o desenvolvimento, fui organizando o código para deixar o aplicativo mais fácil de entender e utilizar. Com esse trabalho, consegui praticar os conhecimentos de Flutter e Dart e entender melhor como construir um aplicativo com diferentes telas e funcionalidades.
